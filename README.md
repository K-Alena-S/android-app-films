# Приложение "Список фильмов"

Это мобильное приложение, реализующее просмотр и фильтрацию списка фильмов. На главном экране отображается заголовок "Фильмы" в шапке. При запуске показывается индикатор загрузки, пока данные о фильмах загружаются. Если загрузка не удалась, отображается всплывающее сообщение об ошибке.

В основном списке сначала отображается заголовок "Жанры" и список жанров, полученных из поля `genres` у фильмов. Ни один жанр по умолчанию не выбран. Ниже — заголовок "Фильмы" и список фильмов, отсортированный по локализованному названию (`localized_name`), по алфавиту. Фильмы выводятся по 2 в ряд с изображением афиши и названием, которое занимает не более 2 строк, с добавлением многоточия, если название длиннее.

При выборе жанра он выделяется, и в списке фильмов показываются только фильмы этого жанра. Повторное нажатие снимает выделение и показывает все фильмы. Можно выбрать другой жанр — выделение сменится, и список обновится. Нажатие на фильм открывает экран с подробной информацией.

На экране с подробностями показывается название фильма с стрелкой назад, изображение обложки, локализованное название, список жанров и год выхода, рейтинг и описание.
